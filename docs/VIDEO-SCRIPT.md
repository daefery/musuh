# Naskah video presentasi (2 menit 33 detik)

Suara narasi berbahasa Inggris, subtitle berbahasa Indonesia (ditanam di video, juga tersedia sebagai `.srt`). Cara membuat video ada di `video/README.md`.

| Adegan | Narasi (Inggris, diucapkan) | Subtitle (Indonesia) |
|---|---|---|
| Masalah | Cyber exercises like Keris Woomera 2026 need three teams. A red team attacks, a blue team defends, and exercise control, EXCON, grades every objective GO or NO-GO. Because it takes three teams, exercises like this only happen at big events. | Latihan siber seperti Keris Woomera 2026 butuh tiga tim. Tim merah menyerang, tim biru bertahan, dan EXCON menilai setiap sasaran GO atau NO-GO. Karena butuh tiga tim, latihan seperti ini terikat pada acara besar. |
| MUSUH | This is MUSUH, Indonesian for enemy: an engine that tests attack and resilience. MUSUH replaces the red team and EXCON, on one laptop, with no internet. | Ini MUSUH, Mesin Uji Serangan dan Ketahanan. MUSUH menggantikan tim merah dan EXCON, di satu laptop, tanpa internet. |
| 1 · Siapkan | The trainer picks a scenario. The scenarios are fictional, but every enemy step is based on a public incident. The Red Team pattern from Keris Woomera, the BSSN timeline of the PDNS 2 attack, and the attacks on Ukraine's power grid. The trainee enters a name, and the exercise begins. | Pelatih memilih skenario. Skenarionya rekaan, tetapi setiap langkah musuh bersumber dari insiden publik. Pola Red Team di Keris Woomera, kronologi BSSN atas PDNS 2, dan serangan jaringan listrik Ukraina. Peserta mengisi nama, lalu latihan dimulai. |
| 2 · Operasi | The trainee sees what a real cyber operator sees: the network map, alerts, and logs. Every alert comes from a SigmaHQ detection rule. The web server is forwarding traffic to an outside address. The trainee blocks it. The target is always shown first, before anything runs. | Peserta melihat apa yang dilihat petugas siber sungguhan: peta jaringan, peringatan, dan log. Setiap peringatan berasal dari aturan deteksi SigmaHQ. Server web meneruskan lalu lintas ke alamat luar. Peserta memblokirnya. Sasaran tindakan selalu ditampilkan dulu, baru dijalankan. |
| MUSUH beradaptasi | On the trainer's screen, you can see what MUSUH is thinking. Its route is cut, so it opens a backup tunnel to another address. MUSUH adapts, but it is fair: the same exercise code and the same actions always produce the same enemy. | Di layar pelatih terlihat pikiran MUSUH. Jalurnya diputus, maka ia membuka terowongan cadangan ke alamat lain. MUSUH beradaptasi, tetapi adil: kode latihan dan tindakan yang sama selalu menghasilkan musuh yang sama. |
| Serahkan konsol | The trainee blocks that tunnel too, and declares an incident. Then the console is handed over. The remaining time still plays out, so nobody earns a GO by stopping early. | Peserta memblokir terowongan itu dan menyatakan insiden. Lalu konsol diserahkan. Sisa waktu tetap dijalankan, jadi tidak ada nilai GO karena berhenti lebih awal. |
| 3 · Evaluasi | The evaluation reveals everything: the score, each objective, and the enemy's attack chain. The timeline puts the enemy's moves next to the trainee's actions. Every enemy step opens to show its source. | Evaluasi membuka semuanya: nilai, sasaran latihan, dan rantai serangan musuh. Garis waktu menyandingkan langkah musuh dengan tindakan peserta. Setiap langkah musuh bisa dibuka untuk melihat sumbernya. |
| 4 · Rapor | The result is a cyber achievement report. MUSUH checks it by replaying the whole exercise from the start. This report is valid. If someone edits the report file, say, raising the score to 98, the replay instantly shows the real score. That report is not valid. | Hasilnya adalah Rapor Prestasi Siber. MUSUH memeriksanya dengan memutar ulang latihan dari awal. Rapor ini sah. Bila berkas rapor diubah, misalnya nilainya dinaikkan menjadi 98, putar ulang langsung menunjukkan nilai aslinya. Rapor itu tidak sah. |
| Skenario listrik | Another scenario hits the base's power supply. MUSUH shuts down the generator over Modbus. Restarting the generator is refused, because the enemy could simply shut it down again. Once Modbus write commands are blocked, the generator runs again. | Skenario lain menyerang pasokan listrik markas. MUSUH mematikan genset lewat Modbus. Menyalakan genset ditolak, karena musuh masih bisa mematikannya lagi. Setelah perintah tulis Modbus diblokir, genset menyala kembali. |
| Penutup | MUSUH. One program, no internet, for every unit. A fair opponent. A score anyone can check. | MUSUH. Satu program, tanpa internet, untuk setiap satuan. Lawannya adil. Nilainya bisa diperiksa ulang. |

Suara sintetis Kokoro TTS (model terbuka, Apache 2.0, dijalankan di laptop), suara `af_heart`. Video tidak mengklaim MUSUH sudah dipakai TNI; batasan ada di `LIMITS.md`.
